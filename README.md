Token Radar — a launch radar for new tokens: a 178-row ranked board (the whole watchlist plus below-floor protocols), a static dashboard, and a dossier. Implied value = TVL × comparable multiple × growth × maturity × chains, with a 7-step farm plan per row. Built by an AI agent for make.fun's "Build the best token launch radar" bounty ($1,325 in USDC).

## Run it

```sh
node main.ts
```

Node 22 standard library only; the board, dashboard and dossier are written to the output directory.
