Live-token protocols are kept apart and shown as the market's own values, never mixed into the ranking.

How the value is worked out

Implied value = TVL × comparable multiple × growth × maturity × chains. The multiple is the median market-cap / TVL of the live-token protocols in the same category, blended half and half with the all-category median, so no protocol is scored on a name the model never saw. Growth is the 7-day change, clamped to −60%..+120% and weighted by half. Maturity rises with how long the protocol has run with no token, from 0.6 to 1.0 over three years. Chains adds 2% per extra chain, up to five.

implied = TVL × multiple × (1 + growth × 0.5) × (0.6 + age / 1095 × 0.4) × (1 + 0.02 × chains)

A protocol is called pre-token because its record carries no token — no market cap, no CoinGecko id, no symbol — never that it has none. Implied value is a model from the snapshot's own figures, not a promise of an airdrop or a price.

Why some big names are absent

Above the floor, only the watchlist itself is ranked. A large protocol the watchlist leaves out is usually a product or an arm of another protocol — a curator's vault, an exchange's international arm, a gateway — and its launch is not its own. Below the floor, the board ranks every pre-token protocol that passes the same no-wrapped, no-staked, no-bridged test the watchlist uses.
